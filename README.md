# Student_Marks_Predictor
A full-stack Django + Machine Learning application that predicts student exam marks using Linear Regression based on study habits and academic performance.

🚀 About the Project

The AI Student Marks Predictor is a Machine Learning-powered web application developed using Python, Django, Scikit-learn, Pandas, NumPy, HTML, CSS, and JavaScript. The project is designed to predict a student's expected examination score based on important academic and lifestyle factors such as study hours, attendance, sleep hours, internet usage, completed assignments, and previous examination scores.

The application combines a Linear Regression Machine Learning model with a Django web application, allowing users to enter their academic information through a modern, responsive interface and instantly receive a predicted examination score. This project demonstrates the practical integration of Machine Learning with Full-Stack Web Development.

❗ Problem Statement

Many students find it difficult to estimate how their daily study habits and academic performance influence their final examination results. They often rely on assumptions rather than data, making it challenging to identify areas that need improvement before exams.

Educational institutions and students also lack a simple, intelligent, and interactive prediction system that can analyze multiple academic factors and provide a realistic estimate of future examination performance.

✅ Solution

To address this problem, this project implements a Machine Learning-based Student Marks Prediction System using the Linear Regression Algorithm.

The trained model analyzes multiple input parameters provided by the student and predicts their expected examination marks within seconds.

The web application provides a user-friendly interface where students can enter their academic details. The backend processes the information, sends it to the trained Machine Learning model, and displays the predicted score along with a performance evaluation.

This solution helps students:

Understand how their academic habits affect performance
Estimate expected examination marks before exams
Identify areas that require improvement
Plan their studies more effectively
Make informed academic decisions using data-driven predictions
